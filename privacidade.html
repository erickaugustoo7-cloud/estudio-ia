Política de Privacidade

Última atualização: 8 de novembro de 2026

O que é este app

O Mensageiro Publicador é uma ferramenta de uso próprio do responsável pelo canal Mensageiro de Fé. Ele serve apenas para publicar, no YouTube, no Facebook e no Instagram do próprio canal, os vídeos produzidos pelo responsável.

Dados coletados

O app não coleta, armazena nem compartilha dados de outras pessoas. Ele usa somente a autorização concedida pelo próprio administrador às contas que ele administra, para enviar vídeos e consultar o status de cada publicação.

Uso dos dados do Google

O acesso à API do YouTube é usado exclusivamente para enviar vídeos ao canal do próprio administrador. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Nenhum dado é vendido, alugado ou repassado a terceiros.

Exclusão de dados

O app não guarda dados pessoais de usuários. O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions (Google) ou nas configurações de Apps e sites do Facebook.
